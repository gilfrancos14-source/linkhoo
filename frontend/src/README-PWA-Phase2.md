# Intégration des fonctionnalités PWA Phase 2\n\nCe guide explique comment intégrer les nouvelles fonctionnalités PWA avancées (Phase 2) dans l'application Ileyha Location existante.\n\n## Vue d'ensemble\n\nLa Phase 2 PWA transforme l'application en une expérience hors-ligne avancée avec :\n\n1. **Notifications push** - Notifications instantanées pour les réservations, messages et actualités\n2. **Synchronisation hors-ligne** - File d'attente intelligente pour les requêtes hors-ligne\n3. **Formulaires hors-ligne** - Sauvegarde automatique des données de formulaire\n4. **Install prompt** - Invitation à installer l'application sur l'appareil\n5. **Optimisation du cache** - Gestion avancée du cache avec optimisation d'images\n6. **Gestion du cache** - Interface utilisateur pour gérer l'espace de stockage\n\n## Étapes d'intégration\n\n### 1. Mise à jour du service worker\n\nLe service worker a déjà été mis à jour avec toutes les fonctionnalités Phase 2. Le fichier `sw.js` contient :\n\n- Cache stratifié (statique, dynamique, images, file d'attente)\n- Gestion des requêtes API avec file d'attente hors-ligne\n- Optimisation d'images automatique\n- Synchronisation périodique\n- Gestion des notifications push\n\n### 2. Intégration des hooks\n\n#### usePushNotifications\n\n```typescript\nimport { usePushNotifications } from './hooks/usePushNotifications';\n\nconst MyComponent = () => {\n  const { permission, requestPermission, supported } = usePushNotifications();\n  \n  if (!supported) {\n    return <div>Les notifications ne sont pas supportées par ce navigateur</div>;\n  }\n  \n  switch (permission) {\n    case 'granted':\n      return <div>Notifications activées</div>;\n    case 'denied':\n      return <div>Notifications refusées</div>;\n    case 'default':\n      return (\n        <button onClick={requestPermission}>\n          Activer les notifications\n        </button>\n      );\n  }\n};\n```\n\n#### useOfflineQueue\n\n```typescript\nimport { useOfflineQueue } from './hooks/useOfflineQueue';\n\nconst MyComponent = () => {\n  const { status, syncAll, retryFailed, clearQueue } = useOfflineQueue();\n  \n  return (\n    <div>\n      <p>Requêtes en attente: {status.pendingRequests.length}</p>\n      <button onClick={syncAll} disabled={status.isSyncing}>\n        Synchroniser maintenant\n      </button>\n    </div>\n  );\n};\n```\n\n#### useOfflineForm\n\n```typescript\nimport { useOfflineForm } from './hooks/useOfflineForm';\n\nconst MyForm = () => {\n  const fields = [\n    { name: 'name', label: 'Nom', type: 'text', required: true },\n    { name: 'email', label: 'Email', type: 'email', required: true }\n  ];\n  \n  const { state, getField, updateField, submit } = useOfflineForm(\n    fields.map(field => ({ name: field.name, value: '', touched: false })),\n    {\n      validate: (values) => {\n        const errors: Record<string, string> = {};\n        if (!values.name) errors.name = 'Le nom est requis';\n        if (!values.email) errors.email = 'L\\'email est requis';\n        return Object.keys(errors).length > 0 ? errors : null;\n      },\n      onSubmit: async (values) => {\n        // Envoyer les données au serveur\n        const response = await fetch('/api/submit', {\n          method: 'POST',\n          headers: { 'Content-Type': 'application/json' },\n          body: JSON.stringify(values)\n        });\n        return response.json();\n      }\n    }\n  );\n  \n  return (\n    <form onSubmit={handleSubmit}>\n      {fields.map(field => {\n        const fieldValue = getField(field.name);\n        return (\n          <div key={field.name}>\n            <label>{field.label}</label>\n            <input\n              type={field.type}\n              value={fieldValue.value}\n              onChange={(e) => updateField(field.name, e.target.value)}\n            />\n            {fieldValue.touched && fieldValue.error && (\n              <div>{fieldValue.error}</div>\n            )}\n          </div>\n        );\n      })}\n      <button type=\"submit\" disabled={state.isSubmitting}>\n        {state.isSubmitting ? 'Envoi...' : 'Envoyer'}\n      </button>\n    </form>\n  );\n};\n```\n\n#### useInstallPrompt\n\n```typescript\nimport { useInstallPrompt } from './hooks/useInstallPrompt';\n\nconst InstallButton = () => {\n  const { isInstallable, isInstalled, installPrompt, showInstallPrompt } = useInstallPrompt();\n  \n  if (!isInstallable || isInstalled) {\n    return null;\n  }\n  \n  return (\n    <button onClick={showInstallPrompt}>\n      Installer l'application\n    </button>\n  );\n};\n```\n\n#### useCacheManager\n\n```typescript\nimport { useCacheManager } from './hooks/useCacheManager';\n\nconst CacheInfo = () => {\n  const { stats, refreshStats, optimizeCache, clearAllCaches } = useCacheManager();\n  \n  return (\n    <div>\n      <button onClick={refreshStats}>Rafraîchir</button>\n      <p>Espace utilisé: {stats?.totalSize} bytes</p>\n      <button onClick={optimizeCache}>Optimiser</button>\n      <button onClick={clearAllCatches}>Effacer tout</button>\n    </div>\n  );\n};\n```\n\n### 3. Intégration des composants UI\n\n#### PWAControlPanel (Recommandé)\n\nLe composant `PWAControlPanel` combine toutes les fonctionnalités PWA en un seul panneau de contrôle :\n\n```typescript\nimport PWAControlPanel from './components/PWAControlPanel';\n\nconst App = () => {\n  return (\n    <div>\n      {/* ... contenu de l'application ... */}\n      <PWAControlPanel \n        className=\"main-control-panel\"\n        showNotifications={true}\n        showOfflineQueue={true}\n        showInstallPrompt={true}\n        showCacheManager={true}\n        autoShow={false}\n      />\n    </div>\n  );\n};\n```\n\n#### Composants individuels\n\nVous pouvez aussi utiliser les composants individuellement :\n\n```typescript\nimport PushNotificationBanner from './components/PushNotificationBanner';\nimport OfflineQueueStatus from './components/OfflineQueueStatus';\nimport InstallPrompt from './components/InstallPrompt';\nimport CacheManager from './components/CacheManager';\nimport OfflineForm from './components/OfflineForm';\n\nconst App = () => {\n  return (\n    <div>\n      {/* ... contenu de l'application ... */}\n      \n      {/* Bannière de notifications */}\n      <PushNotificationBanner />\n      \n      {/* Statut de la file d'attente hors-ligne */}\n      <OfflineQueueStatus />\n      \n      {/* Invite d'installation */}\n      <InstallPrompt />\n      \n      {/* Gestionnaire de cache */}\n      <CacheManager />\n      \n      {/* Formulaire hors-ligne */}\n      <OfflineForm \n        fields={[\n          { name: 'name', label: 'Nom', type: 'text', required: true },\n          { name: 'email', label: 'Email', type: 'email', required: true }\n        ]}\n        onSubmit={handleSubmit}\n      />\n    </div>\n  );\n};\n```\n\n### 4.
