Questions fréquentes

Vous avez une question ? Voici les réponses aux questions les plus courantes.

Comment publier une annonce sur Linkhoo ?

Créez un compte, cliquez sur « Publier une annonce », renseignez les informations et photos de votre logement, puis validez.

Comment fonctionne la location directe ?

Vous échangez directement avec le propriétaire, sans intermédiaire, pour visiter et conclure la location.

Quels sont les moyens de paiement acceptés ?

Les moyens de paiement disponibles dépendent de votre pays. Consultez la page d'aide pour le détail.

Comment signaler un problème avec une annonce ?

Utilisez le bouton « Signaler » sur la fiche de l'annonce ou écrivez-nous via le formulaire ci-dessus.

Puis-je contacter un propriétaire directement ?

Oui, les coordonnées du propriétaire sont accessibles depuis chaque annonce.

Linkhoo est-il disponible dans tous les pays d'Afrique de l'Ouest ?

Linkhoo est disponible dans 12 pays d'Afrique de l'Ouest. Utilisez le sélecteur de pays en haut de page.
